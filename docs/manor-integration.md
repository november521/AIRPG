# 主工程庄园原型

工作包 A-MANOR / 负责人本任务 / 独立复核待分配。用户已要求主工程整合并自行试玩。

打开 `game/project.godot`，F5 → 开始游戏 → 死光 → 进入庄园原型。
原雨夜汽车预览已换成庄园外观。独立 output 项目和源 Blender 文件保留；主工程不依赖它们。

| 操作 | 按键 |
| --- | --- |
| 第一人称移动 / 转向 | WASD / 鼠标 |
| 慢走 | Shift |
| 调查员档案、技能、背包、背景 | E 开关；Esc 关闭 |
| 释放 / 恢复鼠标 | Esc / 左键 |
| 回侧门 / 到地窖 | R / B |
| 返回故事档案列表 | F1 或档案底部按钮 |

总览按参考图的左身份/状态、中属性/背景、右技能/物品分区；头像与图标为占位。
背包物品页显示数量、说明、使用/丢弃按钮；操作同时刷新生命与数量。
初始血量 70/100、理智 60/100、六属性 50、侦查/心理学 40，其余未导入字段显示待导入。
演示补给一次恢复 15 生命并扣除一个；满血不消耗，关键物品禁止丢弃。
底部受伤、理智、补给和重置按钮仅供演示，不代表正式规则。

代码入口：bootstrap/main → 本地启动端口 → bootstrap/manor_play。
结构资源在 presentation/manor，角色用例在 application/character，原子状态在 domain/character，
档案 UI 在 presentation/character，合成数据仅在 bootstrap/character_preview。
返回后重进会新建演示角色；位置复位不改变背包。没有磁盘存档、正式剧情、AI、检定或真实拾取。

此前统一验证与截图结果见 testing.md；本次用户要求不再追加测试。复核重点：
快速 E/Esc/F1 的焦点与鼠标恢复、楼梯上下行净空、重复/过期物品操作不部分提交。
不同 DPI、导出包、性能与独立对抗签字待后续验收。
