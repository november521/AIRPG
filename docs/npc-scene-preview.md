# 场景 NPC 漫步与问候原型

2026-10-02。工作包 C-NPC / 负责人本任务 / 独立复核待分配。PRD 8.1、9.1、10.4；基线 main 庄园接入；范围为 game 内庄园展示、探索应用用例、输入、bootstrap、本地化与回归测试。没有改变正式内容包、故事状态或存档格式。

用户要求加入《死光》人物并支持自由移动、简单问候。授权人物资料/名单尚未导入，已经询问用户；身份接入仍待回复。当前接待室和医生书房各放一个明确标注“身份待确认”的合成人形，只用于验证能力，不能称为正式《死光》NPC。出生点、漫步区域和服装颜色都是工程演示数据，不推定人物位置、外形、关系或故事事实。

从主菜单进入庄园后，NPC 在房间限定区域内选择目的地，以 0.65 米/秒走动和短暂停留，使用真实墙体/地面碰撞；卡住时重选目的地。没有全屋导航、跨楼层寻路或离场自主模拟。外形为程序几何占位，尚无角色美术或步行动画。

靠近并面向 NPC，2.4 米内且视线未被墙体挡住时显示 F 交谈提示。F 打开本地固定“你好。”，当前 NPC 和玩家暂停；F/Esc 或结束按钮关闭。E 切换档案时结束交谈；F1 返回故事档案，销毁此会话。没有模型请求、知识资料、选项/自由输入、剧情或状态变化。

bootstrap/npc_preview 是合成名单及会话专属随机端口的组装位置。application/exploration/npc_presence 返回深拷贝名单、漫步目的地及问候结果，拒绝未知身份、非法距离、超距、遮挡与重复打开；presentation 负责物理移动、视线与 UI。用例并非 JSON 外部边界，不新增正式数据 Schema。

验证：指定 D:/Godot 的固定 4.7.2 引擎运行 scripts/verify.ps1；98 个文件依赖检查、3 项负向架构检查、246 项行为检查零失败，导入/完成标记/实际启动通过。原 .tools 控制台入口在本机未正常返回版本，因此未调整验证门槛，改用本机已安装且精确版本一致的引擎。

实际 RTX 4060 图形渲染截图已核对，保存在 artifacts/npc-greeting-preview.png；修正近距离名牌过大与交谈时错误的“单击继续”提示。画面仅验证几何占位、本地化文字及交谈框，不代表角色美术验收。

对抗重点：隔墙/背向/远距不得交谈，连续按键不得重复打开，E/Esc/F1 不残留暂停状态，返回重进不能复用旧 NPC 会话，漫步不能穿墙或坠落。独立复核、不同 DPI、导出包与真实外部设备未验证。待用户提供姓名和位置后替换合成名单；正式角色美术和授权台词另行接入。未提交、推送、发布或创建 PR，保留工作区原有改动。分支 feature/npc-scene-preview；当前任务顺序修改现有工作区，未创建或声称独立 checkout。
