# ADR 0004：故事档案组件与开发占位选项

日期：2026-09-28。依据用户本轮侧栏构图、文字模块化和多故事占位需求。

- 标题、标签、简介分别使用 components 下独立原生场景和脚本；卡片与详情复用
  标题/标签。布局在 .tscn、样式在主题/场景，文案只从本地化键读取，不拼接序号。
- 正式目录 catalog.json v1 不变；preview_catalog.json 单独存放三个界面占位，
  使用同一 Schema 校验，合并前再次验证重复 ID。没有导入 tests 目录中的替身或数据。
- app 配置新增可选布尔 story_archive_placeholders，缺省 false。当前开发配置为 true，
  仅在 OS.is_debug_build() 同时成立时加载。发布构建不展示，占位配置不能改变正式目录。
- 组装层给校验后的占位元数据加 preview_only 标记；UI 显示明确提示并禁用进入，
  应用层亦拒绝其启动请求（STORY_PREVIEW_ONLY），不会触达真实启动端口。
- 原 app schema_version 保持 1：新消费者兼容旧配置；旧消费者会按原严格规则拒绝
  包含新增字段的配置。回退时移除该可选字段，无状态或内容格式迁移，不放宽 Schema。
- 三种纯渐变封面明确标作美术占位，不冒称正式故事插画。

测试消费者已更新组件路径并增加占位默认关闭、独立加载、启动拦截、UI 禁用和
键盘滚动检查。用户随后明确今后测试和验收由其负责；不得据此安排自动测试/窗口操作。
