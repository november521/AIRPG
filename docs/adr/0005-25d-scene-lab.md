# ADR 0005：独立 2.5D 场景实验模板

日期：2026-10-02。状态：实验方案；正式项目整合待后续工作包。

用户要求搜索 GitHub 可借鉴项目并搭建 Godot 2.5D 模板。既有 PRD 是俯视 2D 为主，因此本轮先产出 `output/scene_25d_template/game` 独立项目，不自行改写产品范围或正式故事入口。

方案：原生 Node3D 场景、45° 正交 Camera3D、CharacterBody3D 碰撞和平面 AnimatedSprite3D 角色。每帧位置为展示状态；无剧情状态写入。输入放 infrastructure，bootstrap 唯一装配，展示不直接访问输入全局。固定文本走本地化资源，沿用 4.7.2 精确引擎版本和现有依赖检查规则。

未变更共享业务契约、状态或内容格式。模板使用本机演示角色和合成几何；不是正式内容包。第三方仅作思路参考，不复制许可未经核实的代码和资源。

正式接入需通过独立工作包提供探索用例装配、坐标映射、场景生命周期与退出清理测试，再评估是否更新 PRD 的视觉章节。调研、使用方式和限制见模板 README。
