# ADR 0006：庄园内的角色与背包状态原型

日期：2026-10-02。状态：独立原型；正式主工程接入待后续工作包。

后续状态：已按用户要求在 ADR 0007 接入主工程的庄园原型；下面独立目录边界为本 ADR 初次交付范围。原型内存格式仍未成为正式角色/存档契约。

用户要求先在庄园场景制作背包、血量和信息系统，界面使用简单占位。工作包 C-GA3 / 负责人本任务 / 独立复核待分配；涉及 PRD §7、12、16、17。目录仅限 `output/greenapple_manor_playtest` 及文档，不改正式角色、规则、剧情或 PRD。依赖当前庄园第一人称原型。

## 层次

- `domain/character/character_state.gd`：角色生命/理智与背包数量的状态、定义校验和原子提交。
- `application/character/character_service.gd`：只读视图、使用/丢弃物品用例；显式隔离的 `preview_action` 供开发测试。
- `presentation/character/character_hud.gd`：持有应用服务，不持有领域状态；头像矩形、血量/理智条、角色信息及物品列表。
- `infrastructure/input`：鼠标及输入阻断；打开面板释放鼠标并停止移动、转向，关闭恢复。
- `bootstrap/character_preview.gd`：唯一合成数据装配入口；演示属性、技能、物品和增减数值不代表正式公式。

作用域内的应用服务 `changed` 信号通知面板重新读取快照，不是全局事件总线；没有业务 Autoload 或服务定位器。

## 原型状态 v1

仅定义原型内存格式，**不是正式 StateStore 或存档 v1**：

`{schema_version: 1, revision: int, hp: int, hp_max: int, sanity: int, sanity_max: int, inventory: Dictionary<String, int>}`。

拒绝未知字段/版本、布尔或浮点冒充整数、超出上限的血量/理智、未知物品、非正数量和超过 999 的堆叠。最大值在普通事务中不可改。定义包含本地化键、kind、演示 healing、protected；关键物品定义必须受保护。没有新增外部 JSON 边界，所有合成定义由启动代码显式注入；未来数据化时需新建版本化内容 Schema 和外部校验器。

用例读取深拷贝候选，检验预期 revision，完成使用/丢弃/测试命令后一次完整提交。消耗和回血在同一候选中，校验失败不变状态或 revision；成功递增 revision。界面持有的是视图副本及显示 revision。满血拒绝消耗，空数量移除堆叠；关键物品禁止丢弃，工具没有假照明或互动功能。过期点击失败不消耗。

测试重置可恢复演示值但保留单调递增 revision，避免旧操作重新有效。R 位置复位和 B 楼层切换不重置角色数据。没有写盘、读档恢复、死亡/疯狂机制或正式检定公式；血量为零仅用于验证下限，不触发故事结果。

## 验收与正式整合条件

原型套件验证快照隔离、会话隔离、原子消耗、满血、数量不足、关键物品、过期操作、坏候选与失败回滚，另保留庄园碰撞与输入焦点检查。采用主工程同一架构检查，未放宽依赖规则。

正式整合需确认角色与规则/内容定义，扩展正式状态事务和磁盘存档格式，提供迁移与消费者测试，隔离或剔除演示按钮与数据。当前没有把原型 schema 加入共享正式契约。

## 档案展示扩展（2026-10-02）

用户提供参考布局，要求 E 打开背包并把数据展示在对应位置。原型 profile 只读视图从统一 attribute_value/skill_value 扩为六项 `attributes` 和五项 `skills` 字典，并增加可空 age、condition_key、background 本地化键映射；合成夹具由 bootstrap 注入。六项属性仍使用原来的演示 50，侦查/心理学仍为 40，其余技能、年龄、背景明确待导入，没有复制参考图中的人物或数值。此扩展不改变领域内存状态 v1，也不增加外部内容或存档格式。

全屏档案有总览/技能/随身物品/背景与经历四页。总览左侧身份/状态，中间属性/背景，右侧技能/物品摘要；物品页继续调用同一应用用例。所有页面从同一深拷贝视图刷新，使用物品后同时更新背包和生命显示，保留当前选中页签。E 开关、Esc 关闭；不再占用 Tab，保留界面键盘焦点遍历。头像/图标为色块占位。UI 分为 widgets、overview 和 hud 三个展示脚本，无新增业务写权限。

原型验证 70 项零失败，含 E 按下/按住、四页、未知技能待导入、属性字段对应、跨页刷新、关键物品禁用丢弃、38 项领域/用例失败路径。四页实际 Godot 截图已核对；主工程 156 项回归零失败。不同 DPI、独立对抗复核与真实外部设备未验收。
