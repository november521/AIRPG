# 开始界面：实现与交接

当前美术版本为整幅雨夜庄园封面图（Logo 与菜单排版已画在图内），场景只叠加
可交互文字菜单与标题扫光。最新图层、参数和素材来源见
[美术接入说明](start-screen-art.md)。下述接口与启动方式仍适用；
透明金属 Logo / 烟雾 / 金色轨道的配色记录保留为迭代历史。

本轮依据 2026-09-27 用户确认的改版说明。保留 AIRPG 原 Logo 的 A 与四角星，
采用深黑、旧金、低亮度印记、纵向文字菜单。没有使用参考游戏的图形资产。

## 启动

在当前功能 worktree 的根目录运行（PowerShell 7）：

```powershell
./scripts/start_game.ps1 -Godot 'C:/Users/31286/Desktop/AIRPG/.tools/godot/Godot_v4.7.2-stable_win64_console.exe'
```

脚本定位自身所属项目，先用固定版本引擎导入资源，再启动游戏；不运行测试。
也可导入本 worktree 的 game/project.godot，等待编辑器导入完成后 F5。
直接对一个从未导入的 checkout 使用引擎运行命令，可能缺少纹理导入缓存。

## 功能边界

- 开始游戏：淡出后沿现有 route_requested 信号进入 workspace；正式游戏内容尚未接入。
- 设置：按用户要求可选中、可点击，不执行操作，不显示占位弹窗。
- 退出游戏：淡出后发出 quit_requested，由 bootstrap 处理程序退出。
- 鼠标悬停与原生 UI 焦点共用高亮。方向键、Tab、确认键沿 Godot 原生 UI 动作工作。
- 没有继续/加载存档入口，没有音效资源或设置后端。

## 美术调参

- 设计参考为 1920×1080；封面底图原始 1672×941，按非等比拉伸铺满设计区
  （横 1.148325、纵 1.147715）。
- 封面图内含的 AIRPG 字标位于设计区 (166.5, 210.0)–(886.5, 523.4)，扫光层与
  此矩形一一对应，因此扫光不会被拉伸错位。
- 菜单列：容器 (399, 588)–(639, 854)，行高 72、间距 25、字体 42，
  即三行文字中心 y = 624 / 721 / 818、中心 x = 519。
- 菜单项最小尺寸 240×72，柔光层再向外各扩 160 px，于是左右细线与菱形
  落在 x≈252–784，与封面图里原有的装饰线位置一致。
- 封面 2.4 秒淡入；菜单延迟 0.5 秒、1.2 秒淡入；离场 0.3 秒。
- 材质着色可独立替换。没有使用模仿原游戏的圆环组合、专属文字或符号。

2026-09-27 色彩修订：Logo 采用旧铜暗部、金箔主体、苍金高光三段配色。
磨损改为稀疏氧化与凹点，减少全表面均匀变暗；增加轻微相反方向边缘明暗，
保留原始轮廓。背景印记以局部淡金残光衬托暗铜色线条，菜单选中项偏象牙金。
本轮已查看真实图形窗口，启动日志未出现脚本、纹理或着色器错误；未运行完整测试。
